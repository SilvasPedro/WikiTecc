O que é CGNAT? (Carrier Grade NAT)

O CGNAT é uma tecnologia de rede que permite que um único endereço IP Público seja compartilhado por centenas de usuários simultaneamente. Na ETECC, utilizamos essa técnica para contornar a escassez global de endereços IPv4.

Benefícios

  • Segurança: Atua como um firewall natural, escondendo os dispositivos dos clientes de ataques diretos da internet.
  • Eficiência: Permite o crescimento da base de assinantes mesmo com a falta de novos IPs no mercado.
  • Custo: Reduz a necessidade de compra de blocos caros de IPv4, mantendo planos acessíveis.

Malefícios

  • Jogos Online: Pode causar "NAT Estrito" ou problemas de conexão em partidas P2P (ex: consoles).
  • Acesso Remoto: Dificulta o acesso a câmeras (DVR) e servidores domésticos sem o uso de nuvem (Cloud).
  • Portas Bloqueadas: Como visto, portas de 1 a 1023 são restritas para segurança da rede.

Como o CGNAT funciona na prática?

Diferente do NAT comum (feito no roteador do cliente), o CGNAT ocorre dentro da infraestrutura da ETECC Telecom. O roteador do cliente recebe um IP de uma faixa específica (geralmente 100.64.0.0/10), que é então traduzido para um IP Público antes de sair para a internet.

Resumo de Troubleshooting para o Técnico

Cenário do Cliente Impacto do CGNAT Solução Recomendada
Navegação e Streaming Nenhum Manter CGNAT padrão.
Câmeras (DVR antigo) Bloqueio de acesso Migrar para Cloud ou contratar IP Fixo.
Games (Console/PC) NAT Tipo 3 (Estrito) Verificar suporte a IPv6.

Dica de Ouro: Sempre verifique se o cliente possui **IPv6** ativo. O IPv6 não passa por CGNAT, o que resolve a maioria dos problemas de jogos e acessos externos modernos sem custo adicional para a empresa ou para o cliente.
