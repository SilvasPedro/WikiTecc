Entendendo IP Público, Privado e CGNAT na ETECC

Para o suporte técnico, entender a diferença entre os tipos de IP é fundamental para diagnosticar problemas de acesso externo, jogos online e sistemas de câmeras.

IP Público

É o endereço visível em toda a internet. Único no mundo, permite que o dispositivo seja "encontrado" de qualquer lugar.

IP Privado

Usado apenas dentro da rede local (casa do cliente). Exemplos comuns: 192.168.x.x ou 10.0.x.x.

CGNAT na ETECC Telecom

Devido à escassez mundial de endereços IPv4, a ETECC utiliza o CGNAT (Carrier Grade NAT). Isso significa que vários clientes compartilham o mesmo IP Público para navegar.

Regra de Firewall Interna:

Clientes em CGNAT possuem todas as portas de 1 a 1023 bloqueadas.

Essa medida é aplicada por segurança para proteger a infraestrutura e evitar ataques em portas de serviços críticos (HTTP, FTP, SSH, etc).

Impacto Técnico (Acesso Externo)

Faixa de Portas Status no CGNAT Uso Comum
1 - 1023 Bloqueadas Serviços de Sistema (Web, E-mail, SSH)
1024 - 65535 Disponíveis* Jogos, Apps, P2P (Sujeito a redirecionamento)

*Nota: Mesmo portas altas podem não funcionar em CGNAT sem um IP Fixo ou IP Público exclusivo.

O que responder ao cliente?

  • Se o cliente precisar abrir portas para DVR (Câmeras) ou Servidores, ele provavelmente precisará da contratação de um IP Fixo.
  • Para jogos online, o CGNAT pode causar "NAT Moderado" ou "NAT Estrito".
  • O bloqueio das portas 1-1023 é uma camada de proteção da ETECC para evitar invasões nos roteadores dos assinantes.
